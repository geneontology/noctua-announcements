level: success

apps: [vpe]

expires: 2026-12-31
---

Changes: 

- The comment icon is **always shown** on a row, grey when nothing is written
  yet, so you no longer have to hover to find it.
- Clicking the comment icon on an activity shows **only that activity's
  comments**, rather than every comment in the model.
- New **Evidence dispute** category on evidence comments, which opens a ticket
  on the GO annotation tracker.
- **Annotation dispute** is now **GO term annotation dispute**, to be clear
  about what it applies to. Comments saved under the old name still work and
  are shown under the new one.
- When a comment opens a GitHub ticket, **the comment text is included in the
  ticket** instead of leaving you to paste it in.
- **Ontology term pending** comments can now open a ticket on the GO ontology
  tracker.
